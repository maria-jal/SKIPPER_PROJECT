# Skills and personality study [SKIPPER]

This project examines whether emerging adults can develop their social engagement and emotional resilience skills through interventions.

The preregistration documents for this project are available on OSF under the titles <i>"01 Project description - Skills and Personality [SKIPPER]"</i> and <i>"02 Project adaptations [main study] - Skills and Personality [SKIPPER]"</i> (folder: project_descriptions).

We also preregistered our study hypotheses on OSF in the documents <i>"Preregistration1_mainstudy"</i> and <i>"Preregistration1_mainstudy_hypotheses"</i> (folder: preregistrations).
