# SKIPPER_PROJECT1
Skills and personality study

This project examines whether emerging adults can enhance their social engagement and emotional resilience skills. 
The preregistration of this project is summarized in the documents "00A Project description - Skills and Personality [SKIPPER]" and "00B Project adaptations [main study] - Skills and Personality [SKIPPER]" on OSF.

We preregistered hypotheses for our study also on OSF ("01_Preregistration1_mainstudy" and "01_Preregistration1_mainstudy_hypotheses". The view-only link is: https://osf.io/fzyr3/overview?view_only=f2a9901602d54dbabe7d6642ba141fe6
