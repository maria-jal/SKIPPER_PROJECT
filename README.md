# Skills and personality study [SKIPPER]

This project examines whether emerging adults can develop their social engagement and emotional resilience skills through interventions.

The preregistration documents for this project are available on OSF under the titles <i>"00A Project description - Skills and Personality [SKIPPER]"</i> and <i>"00B Project adaptations [main study] - Skills and Personality [SKIPPER]"</i>.

We also preregistered our study hypotheses on OSF in the documents <i>"01_Preregistration1_mainstudy"</i> and <i>"01_Preregistration1_mainstudy_hypotheses"</i>. The view-only link is: https://osf.io/fzyr3/overview?view_only=f2a9901602d54dbabe7d6642ba141fe6
